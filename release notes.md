# PulseSec release notes

## 1.3.9
- **Updates now come straight from this GitHub repository.**

## 1.3.6 – 1.3.8
- Tamper protection: PulseSec refuses to start if its app files have been altered.
- Automatic updates confirmed working end to end.

## 1.3.4 – 1.3.5
- **Security hardening** — sandboxed windows, locked-down links and permissions, checked settings, size limits on downloads, and stricter updates (https only, size and checksum required).

## 1.3.0 – 1.3.3
- Clickable counts, tiles, sections and SOC panels; search; recent changes; copy summary; pause alerts and mute one service; more places to check for every service; services with issues in the tray menu.
- Setup closes a running PulseSec by itself.
- Fixed: services watched only through the news no longer show "Healthy" when the news can't be read.

> If PulseSec 1.0 – 1.3.0 or 1.3.4 is installed, download **PulseSec-Setup.exe** from this repository once — it updates itself from then on.
